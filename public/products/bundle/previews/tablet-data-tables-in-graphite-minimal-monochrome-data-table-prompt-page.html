Anatomy

Four rules, nothing more.

Hairline dividers

One pixel at 8% opacity. Rows separate without ever shouting.

Generous space

16px vertical padding. Dense data still gets room to read.

Sortable heads

Quiet uppercase labels. The active sort is the only thing in full ink.

One accent

Platinum marks the in-flight state. Everything else is graphite.

The prompt

Paste it. Get the table.

prompt.txt 
Design a minimal monochrome data table for a transactions view.
Hairline row dividers (1px, ~8% ink), generous 16px row padding,
no zebra striping. Columns: select, status, email (sortable),
method, amount (right-aligned, mono). Quiet uppercase headers;
only the active sort column in full ink. A single platinum
accent for the in-flight "processing" state. Toolbar with a
filter input + column toggle. Footer: selection count + prev/next.
Graphite ink on off-white. Calm, premium, deliberate.
#data-table #monochrome #dashboard #minimal
