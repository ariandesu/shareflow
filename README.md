## 🌟 Key Features

* 🚀 **Serverless & Edge First:** Deployed globally on Cloudflare Pages with zero server latency.
* 📁 **WebRTC P2P File Sharing:** Transfer unlimited file sizes encrypted peer-to-peer directly between browsers.
* 📝 **Self-Destructing Text Share:** Share code snippets and secret text with auto-expiring timers and view limits.
* 📦 **Developer Starter Kits:** Instant access to production FastAPI, Async Web Scraper, DevOps PDF, and Salary CSV datasets.
* 🛠️ **39+ Built-In Developer Tools:** JSON Formatter, JWT Decoder, Regex Tester, Base64, UUID Generator, Image Compressor, PDF Merger & more.
* 🌓 **Dark & Light Mode:** High-contrast Apple HIG-inspired user interface.

## 🛠️ Tech Stack

* **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons
* **Edge Functions:** Cloudflare Pages Functions, WebRTC, PDF-Lib
* **Deployment:** Cloudflare Pages CI/CD

## 🚀 Quick Start (Run Locally)

```bash
# 1. Clone the repository
git clone https://github.com/ariandesu/shareflow.git
cd shareflow

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:5173` to see your local app running!
