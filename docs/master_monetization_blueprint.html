3. The AI Website Design Prompts Engine Architecture

Modeled after platforms like SuperDesign.dev, this engine transforms ShareFlow into an authoritative hub for modern AI-assisted web engineering. The feature splits into two complementary vectors: high-traffic Free Giveaways and frictionless SupportKori Micro-Sales.

A. Free Giveaways (Traffic Magnet inspired by SuperDesign.dev)

Free prompts are designed to be instantaneously useful. A visitor clicks "Copy Prompt", receives a comprehensive, expertly crafted markdown prompt calibrated for their tool of choice (v0, Bolt.new, Lovable.dev, Cursor, Windsurf, or Claude Artifacts), and pastes it to generate a complete web UI in seconds.

1. Structural Hierarchy

Specifies semantic HTML, mobile-first breakpoints, sticky navigation, Bento grid galleries, and dynamic hero layouts.

2. Aesthetic Design Tokens

Pre-tuned CSS variables, Tailwind classes, glassmorphic blurs, dark-mode gradients, and micro-interaction states.

3. Interactive Component Logic

Framer Motion spring animations, accessible Radix UI primitives, copy-to-clipboard state, and toast feedback.

4. Prompt Data Schema (`src/types/prompt.ts`)

export type PromptCategory = "Landing Page" | "Dashboard" | "E-Commerce" | "Portfolio" | "Micro-SaaS" | "Mobile UI";
export type TargetTool = "v0" | "Bolt.new" | "Lovable" | "Cursor" | "Claude" | "Universal";

export interface PromptItem {
  id: string;                  // Unique identifier slug (e.g. 'saas-bento-grid-v0')
  title: string;               // Display title
  description: string;         // Short visual & technical summary
  category: PromptCategory;    // Category chip
  targetTool: TargetTool;      // Optimized AI engine
  isFree: boolean;             // True for instant giveaways, False for premium
  priceBdt?: number;           // SupportKori regional pricing (e.g. 49 BDT)
  priceUsd?: number;           // Gumroad international pricing (e.g. 0.99 USD)
  promptContent: string;       // Ready-to-use prompt text with exact instructions
  systemInstruction?: string;  // Optional companion system persona prompt
  previewImage: string;        // Mockup preview image URL
  livePreviewUrl?: string;     // Interactive demo or inspiration URL
  supportKoriUrl?: string;     // SupportKori micro-checkout URL
  gumroadUrl?: string;         // International Gumroad product URL
  tags: string[];              // Filter tags (['dark-mode', 'bento', 'tailwind'])
  features: string[];          // Highlight chips (['Framer Motion', 'TypeScript', 'Lucide'])
  copyCount: number;           // Social proof counter
  active: boolean;             // Publishing state
  createdAt: string;           // ISO timestamp
}

7. Autonomous Multi-Agent & CLI Ingestion Pipeline

Sanctuary / Sera acts as an active catalog curator. Using dedicated Python CLI scripts, the agent can fetch, format, validate, and inject new prompts and wallpaper bundles headless into the platform without manual UI entry.

Wallpapers CLI (`scripts/manage_wallpapers.py`) 
# List all active & draft bundles
python3 scripts/manage_wallpapers.py list

# Ingest new 8K wallpaper pack
python3 scripts/manage_wallpapers.py add \
  --title "Cyber City Neon 8K" \
  --category "Desktop 8K" \
  --resolution "7680x4320" \
  --items 16 \
  --preview "/assets/previews/cyber8k.jpg" \
  --gumroad "https://mhr3d.gumroad.com/l/cyber8k"

# Toggle visibility
python3 scripts/manage_wallpapers.py toggle --id "cyber-city-neon-8k"
