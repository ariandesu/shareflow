3. Wallpaper Bundle Schema & Type Definitions

The data contract enforces strict typing across the frontend React components, server routes, and autonomous management scripts. Every wallpaper pack is self-describing with aspect ratios, color tags, preview links, and Gumroad distribution endpoints. 

// src/types/wallpaper.ts
export type WallpaperCategory = 
  | "Desktop 8K" 
  | "Mobile OLED" 
  | "Dual Monitor" 
  | "3D Sci-Fi" 
  | "Minimalist Dark";

export interface WallpaperBundle {
  id: string;                  // URL-friendly unique slug (e.g., 'cyberpunk-neo-tokyo-8k')
  title: string;               // Display title (e.g., 'Cyberpunk Neo Tokyo 8K Pack')
  description: string;         // Editorial pack description & visual characteristics
  category: WallpaperCategory; // Categorization for filtering
  resolution: string;          // Master pixel dimensions (e.g., '7680x4320 (8K UHD)')
  aspectRatio: string;         // '16:9', '9:19.5', '32:9', '21:9'
  itemCount: number;           // Total wallpapers contained in pack
  format: string;              // 'Lossless PNG', '10-bit HDR TIFF', etc.
  previewUrl: string;          // Public high-resolution cover image URL
  sampleImages?: string[];     // Array of sample preview thumbnail URLs
  price: string;               // Original Gumroad retail value (e.g., '$9.99')
  downloadUrl: string;         // Direct cloud/storage link or mirror zip
  gumroadBaseUrl: string;      // Base checkout URL (e.g., 'https://mhr3d.gumroad.com/l/tokyo8k')
  features: string[];          // Highlighting chips (e.g., 'OLED True Black', 'HDR10 Color Profile')
  tags: string[];              // Search keywords (e.g., ['cyberpunk', 'neon', '8k', 'desktop'])
  featured: boolean;           // High-priority banner placement in catalog
  active: boolean;             // Immediate visibility flag (true = live, false = draft)
  createdAt: string;           // ISO 8601 creation timestamp
}

4. Dual Backend API & Security Protocol

All administrative mutation requests (bundle creation, status toggling, deletion) are guarded by ShareFlow’s Telegram 2FA session token (`sf_admin_authed_token`). Public reads are rate-limited and cached.

Method Endpoint Auth Requirement Description & Payload Contract
GET /api/wallpapers Public (Open) Returns active wallpaper bundles. If query ?all=true with Admin Token, returns drafts as well.
POST /api/wallpapers Admin 2FA Token Upserts a bundle. Validates title, previewUrl, resolution, and gumroadBaseUrl. Persists to disk/KV.
PATCH /api/wallpapers/:id Admin 2FA Token Updates active status or metadata fields (e.g. {"active": false}) without full payload.
DELETE /api/wallpapers/:id Admin 2FA Token Deletes bundle permanently from JSON catalog / KV store. Returns deletion confirmation.

7. Autonomous AI Ingestion Engine (`scripts/manage_wallpapers.py`)

To enable Sanctuary / Sera to autonomously add, categorize, and deploy wallpaper bundles from local disk or render generation outputs, a dedicated Python CLI script provides direct headless management. 

# Ingestion CLI Capabilities:
# 1. Inspect existing catalog
python3 scripts/manage_wallpapers.py list

# 2. Add new bundle programmatically
python3 scripts/manage_wallpapers.py add \
  --title "Neon Horizon 8K Pack" \
  --category "Desktop 8K" \
  --resolution "7680x4320" \
  --items 12 \
  --preview "https://shareflow.mhr3d.online/assets/previews/neon_8k.jpg" \
  --gumroad "https://mhr3d.gumroad.com/l/neon8k" \
  --tags "neon,synthwave,8k,desktop"

# 3. Toggle visibility or batch import from directory
python3 scripts/manage_wallpapers.py toggle --id "neon-horizon-8k-pack"
python3 scripts/manage_wallpapers.py scan-dir --path "/home/mahir-linux/Documents/renders"
